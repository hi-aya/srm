# Documentation technique – Supplier Risk Management System (SRMS)

Cette documentation décrit l’architecture technique du projet SRMS en suivant strictement la structure des répertoires du projet.  
Elle vise à faciliter la compréhension, la maintenance et l’extension du système.

---

## 1. Architecture globale du projet

Le projet est organisé en deux blocs principaux :

- **Backend** : logique métier, Machine Learning, API, RAG, persistance
- **Frontend** : interface utilisateur, visualisation, interaction avec l’API
